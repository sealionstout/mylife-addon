# myLife Add-on

A Home Assistant add-on that runs the **myLife** personal dashboard backend on your own hardware.

It aggregates your Home Assistant entities and live BL101 kids' apparel into one
web dashboard served at `http://<your-ha-ip>:8000`. Data stays on your network.

## Install
Add this repository in Home Assistant:
**Settings → Add-ons → Add-on Store → ⋮ → Repositories** → paste this repo's URL → Add.
Then install **myLife Dashboard**, configure your kids' sizes, and Start.

See the add-on's Configuration tab for options (kids/sizes, poll intervals).
